# SSH Manager Documentation

Welcome to the SSH Manager (sshm) documentation hub. This directory contains comprehensive documentation for users, administrators, and developers.

## Overview

SSH Manager is a terminal-based SSH connection manager with secure credential storage, file transfer capabilities, and optional cloud synchronization. The documentation is organized to serve different audiences:

- **Users**: Learn how to install, configure, and use SSH Manager effectively
- **Developers**: Understand the architecture, contribute code, and extend functionality
- **Security Teams**: Review security features, encryption details, and best practices
